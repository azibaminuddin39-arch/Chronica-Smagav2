Mengapa Mode Desktop?

Website CHRONICA didesain dengan detail visual tinggi. Mengaktifkan "Situs Desktop" di HP kamu akan membuat tata letak lebih stabil, rapi, dan memberikan pengalaman membaca berita layaknya aplikasi profesional.

Pengguna Android

  • Buka browser Chrome.
  • Ketuk ikon Titik Tiga (⋮) di pojok kanan atas.
  • Centang kotak Situs Desktop.
Langkah 1: Klik Menu Langkah 2: Centang Situs Desktop

Pengguna iPhone (iOS)

  • Buka browser Safari.
  • Ketuk ikon "aA" di kolom alamat (kiri atas/bawah).
  • Pilih menu Minta Situs Web Desktop.
Langkah: Pilih Menu Desktop
