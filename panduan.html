Mengapa Mode Desktop?

Website CHRONICA didesain dengan detail visual tinggi. Mengaktifkan "Situs Desktop" di HP kamu akan membuat tata letak lebih stabil, rapi, dan memberikan pengalaman membaca berita layaknya aplikasi profesional.

Pengguna Android

  • Buka browser Chrome di HP kamu.
  • Lihat ke pojok kanan atas, ketuk ikon Titik Tiga (⋮).
  • Cari menu ke bawah, lalu centang kotak Situs Desktop atau Desktop Site.
  • Tampilan web akan memuat ulang secara otomatis menjadi lebih rapi.

Pengguna iPhone (iOS)

  • Buka browser Safari.
  • Lihat ke pojok kiri atas pada kolom alamat web, ketuk ikon "aA".
  • Pilih menu Minta Situs Web Desktop atau Request Desktop Website.
  • Tampilan akan menyesuaikan secara otomatis.
